# AGENT_SPEC

## case
Покупатель интернет-магазина одежды открывает чат: спрашивает о доставке или возврате и получает ответ только из загруженной базы знаний со ссылкой на источник. Если пишет, что вещь пришла повреждённой, агент собирает контакт, номер заказа и описание, показывает черновик и после подтверждения создаёт тикет для сотрудника поддержки.

## resources
| resource | status | details |
|---|---|---|
| model API key | none | Приложение работает с mock по умолчанию; для реальной модели нужен ключ оператора |
| data source | none | Реальная база знаний не предоставлена; пустая до загрузки оператором |
| memory DB | none | Новый Postgres в docker compose |
| external ticket service | none | Тикеты хранятся локально в Postgres |
| budget | none | Лимит по умолчанию 0.05 USD на запуск; реальные вызовы только после настройки |

## goal
Metric: доля ответов о доставке и возврате с подтверждающим источником и тикетов без дублей
Target: 100% ответов со ссылкой или честным отказом; 100% подтверждённых тикетов создаются один раз

## users
Users: покупатель в чате; сотрудник поддержки просматривает тикеты
Surfaces: chat
